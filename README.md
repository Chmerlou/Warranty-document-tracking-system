# Система учета гарантийных документов

Консольное приложение для централизованного учета гарантийных документов,
контроля сроков гарантии и поиска сведений о товарах, клиентах и продавцах.

## Назначение

Приложение заменяет бумажный и разрозненный учет гарантийных документов
единой электронной базой. Оно позволяет хранить несколько документов,
контролировать сроки гарантии, искать и сортировать записи, а также получать
уведомления о скором окончании гарантийного срока.

## Целевая аудитория

- сотрудники сервисных центров и магазинов;
- менеджеры по гарантии;
- администраторы системы;
- клиенты, которые в перспективе смогут просматривать свои гарантии.

## Предметная область

Предметная область охватывает регистрацию товара, клиента, продавца и
подтверждающего гарантию документа. Для документа учитываются дата начала,
продолжительность и дата окончания гарантии.

## Основные сущности

- **Пользователь** — сотрудник системы с ролью и учетными данными.
- **Клиент** — физическое или юридическое лицо, владелец товара.
- **Товар** — объект гарантии: наименование, модель и серийный номер.
- **Гарантийный документ** — талон, чек или иной подтверждающий документ.
- **Поставщик / продавец** — организация, реализовавшая товар.
- **Сервисное обращение** — запись о ремонте или обслуживании по гарантии.
- **Категория товара** — классификатор для группировки товаров.

## Возможности

- просмотр всех гарантийных документов;
- добавление и удаление документов;
- расчет даты окончания и текущего статуса гарантии;
- поиск по номеру документа, клиенту, товару и продавцу;
- фильтрация документов по статусу гарантии;
- поиск гарантий, истекающих в течение 30 дней;
- сортировка документов по дате окончания;
- сохранение данных в JSON и загрузка при запуске;
- защита от некорректного пользовательского ввода и ошибок файлов.

## Основные функции

- `calculate_end_date()` рассчитывает дату окончания гарантии.
- `get_warranty_status()` определяет текущий статус гарантии.
- `days_until_expiration()` определяет число оставшихся дней.
- `get_expiration_notice()` формирует уведомление о сроке гарантии.
- `create_warranty_document()` добавляет документ в коллекцию.
- `find_warranty_documents()` выполняет поиск документов.
- `filter_documents_by_status()` фильтрует документы по статусу.
- `filter_expiring_documents()` находит скоро истекающие гарантии.
- `sort_warranty_documents()` сортирует документы.
- `load_documents()` и `save_documents()` работают с JSON-хранилищем.

## Требования

- Python 3.9 или новее;
- pytest;
- flake8.

Установка зависимостей:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Запуск программы

```bash
python3 main.py
```

После запуска отображается главное меню. Все изменения сохраняются в
`data/warranty_documents.json` при выборе пункта выхода.

## Запуск тестов

```bash
pytest -v
```

## Проверка качества кода

```bash
flake8 .
```

## План развития

На следующих этапах планируется:

- переход от словарей к объектной модели предметной области;
- разработка веб-приложения на Django;
- подключение PostgreSQL;
- реализация пользователей, ролей и аутентификации;
- полноценные операции создания, просмотра, изменения и удаления данных;
- разработка REST API с использованием Django REST Framework;
- контейнеризация приложения с Docker и docker-compose;
- настройка CI/CD для сборки, тестирования и развертывания;
- личный кабинет клиента для просмотра статуса гарантии.
