# Система учета гарантийных документов

## Назначение

Веб-приложение для централизованного учета, хранения и обработки гарантийных документов. Система позволяет вести базу гарантийных талонов, чеков и сервисных обращений, отслеживать сроки гарантии, привязывать документы к товарам, поставщикам и клиентам, а также своевременно уведомлять о скором окончании гарантийного срока.

Приложение решает задачи:
- замены бумажного и разрозненного учета гарантийных документов на единую электронную базу;
- быстрого поиска и фильтрации документов по товару, клиенту, поставщику, дате;
- контроля сроков действия гарантии и истории сервисного обслуживания;
- разграничения доступа пользователей к данным.

## Целевая аудитория

- **Сотрудники сервисных центров и магазинов** — оформляют и ведут гарантийные документы.
- **Менеджеры по гарантии** — контролируют сроки, обрабатывают обращения.
- **Администраторы системы** — управляют пользователями и справочниками.
- **Клиенты** (в перспективе) — просматривают статус своей гарантии через личный кабинет.

## Предметная область

Предметная область — учет гарантийных документов на товары и услуги. Она охватывает процессы регистрации товара, привязки к нему гарантийного талона и чека, оформления сервисных обращений, контроля гарантийного срока и взаимодействия между клиентом, продавцом и сервисным центром.

Область позволяет выделить несколько взаимосвязанных сущностей, хранить их в базе данных, устанавливать между ними связи и реализовать полный набор CRUD-операций.

## Основные сущности

- **Пользователь** — сотрудник системы с ролью и учетными данными.
- **Клиент** — физическое или юридическое лицо, владелец товара.
- **Товар** — объект гарантии (наименование, модель, серийный номер).
- **Гарантийный документ** — талон, чек или иной подтверждающий документ с датой начала и окончания гарантии.
- **Поставщик / продавец** — организация, реализовавшая товар.
- **Сервисное обращение** — запись о ремонте или обслуживании по гарантии.
- **Категория товара** — классификатор для группировки товаров.

## Основные функции

- Регистрация и аутентификация пользователей, разграничение прав по ролям.
- Создание, просмотр, редактирование и удаление гарантийных документов.
- Ведение справочников клиентов, товаров, поставщиков и категорий.
- Привязка гарантийного документа к товару, клиенту и продавцу.
- Поиск и фильтрация документов по сроку гарантии, клиенту, товару, поставщику.
- Уведомление о скором истечении гарантийного срока.
- Регистрация и учет сервисных обращений по гарантии.
- REST API для интеграции с внешними системами.
- Развертывание приложения в Docker-контейнерах.

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django;
- подключение базы данных (PostgreSQL) и проектирование схемы связей между сущностями;
- реализация пользователей, ролей и аутентификации;
- реализация операций создания, просмотра, изменения и удаления данных (CRUD);
- разработка REST API (Django REST Framework);
- контейнеризация приложения (Docker, docker-compose);
- настройка CI/CD для автоматической сборки, тестирования и развертывания.
